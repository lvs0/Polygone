# Polygone — Présentation Projet
### Infrastructure Cryptographique Post-Quantique

---

## 1. Le Problème

**Internet est construit sur du sable cryptographique.**

Les chiffrements RSA et ECC — qui protègent vos bancaires en ligne, vos messages, vos mots de passe — seront cassables par un ordinateur quantique.

- **Ça n'est plus de la théorie.** Des agences comme la NSA ordonnent déjà la migration vers la cryptographie post-quantique (CNSA 2.0, 2022).
- **La fenêtre est courte.** Début 2025, NIST a finalisé les standards. Le marché doit migrer maintenant.
- **Les données sont déjà volées.** Attaques "harvest now, decrypt later" — vos données cryptées sont collectées aujourd'hui pour être déchiffrées demain.

**En 2030, les entreprises qui n'auront pas migré seront en infraction avec NIS2 et le Cyber Resilience Act européen — avec des amendes jusqu'à 4% du chiffre d'affaires mondial.**

---

## 2. La Solution

**Polygone construit la bibliothèque cryptographique post-quantique en Rust** — le langage de programmation le plus sûr au monde.

```
Polygone = Cryptographie post-quantique NIST
         + Performance optimisée (SIMD AVX2/512)
         + Sécurité mémoire Rust (zero CVE)
         + Prête pour la production
```

**Trois algorithmes NIST finalisés intégrés :**
- **ML-KEM (Kyber)** — échange de clés post-quantique
- **ML-DSA (Dilithium)** — signatures numériques post-quantiques
- **SLH-DSA (SPHINCS+)** — signatures hash-based (backup)

**Le tout avec une API simple** — remplacement direct d'OpenSSL pour la plupart des cas d'usage.
