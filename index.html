The Metadata Problem

Encryption hides the content.
Not the communication.

Traditional encryption protects what you say. It cannot hide that you said it.

🔓

VPN / TLS

The tunnel is encrypted. But source IP, target IP, packet timing, and message size remain visible to any observer on the path.

🧅

Tor

Circuit switching hides the exit node. But timing correlation attacks still link sender and receiver. Metadata persists.

⬡

Polygone

The message does not travel from A to B. It enters a mathematical state across 7 distributed nodes — and vaporizes in 30 seconds.

💎

Post-Quantum

Even a quantum computer cannot reconstruct a message from fewer than 4 of 7 Shamir fragments. ML-KEM-1024 secures the handshake.

Protocol

Four layers. One guarantee.

From handshake to vaporization — each layer addresses one dimension of the metadata problem.

01

ML-KEM Handshake

Quantum-resistant key exchange. The session key is derived from a shared secret that no quantum computer can recover.

post-quantum · ~34µs
02

BLAKE3 Node Selection

7 nodes are deterministically selected from the DHT using BLAKE3. The selection is reproducible — but unpredictable without the session key.

deterministic · Kademlia DHT
03

Shamir Dispersion

Message is encrypted with AES-256-GCM, then split into 7 fragments via Shamir secret sharing (4-of-7 threshold). Each fragment is sent to a different node.

4-of-7 · AES-256-GCM
04

30s Vaporization

Fragments TTL expires after 30 seconds. No fragment alone contains information. The message ceases to exist.

ephemeral · auto-evaporate

Ecosystem

A complete post-quantum stack.

Seven crates. Each solves one part of the privacy problem. Together, they make privacy architectural.

⬡

Polygone Core

The CLI and library. ML-KEM-1024, Shamir 4-of-7, AES-256-GCM. The protocol implementation.

cargo: polygone
🧠

Polygone-Brain

The intelligence layer. Peer discovery, routing heuristics, adaptive quorum sizing, and threat modeling.

cargo: polygone-brain
🛡️

Polygone-Hide

Post-quantum SOCKS5 tunnel. Turns any TCP connection into a Polygone-encrypted, metadata-shielded flow.

cargo: polygone-hide
💾

Polygone-Drive

Encrypted distributed file storage. Files are sharded, encrypted, and dispersed across the network.

cargo: polygone-drive
🖥️

Polygone-Shell

Secure cloud terminal over the Polygone network. Shell sessions that leave no trace.

cargo: polygone-shell
🌐

Polygone-Server

Docker wrapper for deploying persistent relay nodes. Run a node, contribute to the network.

cargo: polygone-server
