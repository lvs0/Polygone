Quick Start

Démarrer en 30 secondes

Cargo install. Deux lignes de code. Tu es dans le réseau.

terminal
# Installer Polygone cargo install polygone # Démarrer un nœud polygone-node --identity ./my-identity.p2p # Envoyer un message chiffré use polygone::{Message, Cipher}; use polygone_crypto::ml_kem::MLKEM1024; let keypair = MLKEM1024::generate(); let message = Message::new("Secret data", &keypair.public); let encrypted = message.encrypt()?; // Partager avec Shamir 4-of-7 use polygone_crypto::shamir::ShamirScheme; let shares = ShamirScheme::split(secret, threshold: 4, total: 7); // Distribue 7 fragments. 4 suffisent pour reconstruire.
