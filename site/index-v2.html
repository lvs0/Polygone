→ Architecture

Dix modules Rust.
Une seule commande.

Polygone est un workspace Cargo. Chaque module a son rôle, son API, ses tests. Tu peux en activer un seul ou tous.

core

polygone-core

Crypto et protocole MSH. Le cerveau cryptographique. Pas de dépendance externe non maîtrisée.

tui

polygone-shell

TUI ratatui 4 onglets (Accueil, Favoris, Services, Paramètres). Compréhensible en 30 secondes.

drive

polygone-drive

Stockage P2P chiffré + Web UI axum. Tes fichiers restent chez toi.

hide

polygone-hide

Proxy SOCKS5 tunnelisé post-quantique. Le réseau que tu traverses ne lit rien.

mesh

polygone-mesh

LAN/WiFi + Bluetooth BLE. Découverte zéro-config. Mesh local pragmatique.

msg

polygone-msg

Messagerie P2P chiffrée bout-en-bout. Pas de serveur central.

brain

polygone-brain

Couche d'intelligence locale. Ask/Doctor. Inference candle_core CPU.

petals

polygone-petals

Référent d'inférence pour d'autres LLM. Distribué, souverain.
